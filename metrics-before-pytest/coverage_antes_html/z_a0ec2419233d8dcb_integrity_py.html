1"""Fail-closed enforcement for ``security.integrity.require_hashes``. 

2 

3When the policy enables ``require_hashes``, every non-local lockfile entry MUST 

4carry a content hash. A missing or empty hash is treated as a FAILURE, never a 

5silent pass -- an unhashed entry could let a tampered lockfile redirect a 

6download without detection. 

7 

8This module only asserts hash-presence on the already-built lockfile entries; 

9it does NOT add a second filesystem hash pass (the install pipeline already 

10computes and records hashes via the lockfile phase). Local deps are exempt, 

11mirroring :func:`apm_cli.deps.registry_proxy.RegistryProxy.find_missing_hashes`
