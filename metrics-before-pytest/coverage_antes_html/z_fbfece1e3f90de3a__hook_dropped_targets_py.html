1"""Private implementation for HookIntegrator.reconcile_dropped_targets. 

2 

3Split out of ``hook_integrator.py`` purely to respect that file's line-count 

4budget (CI file-length guardrail) -- this module is NOT a second 

5target-cleanup authority. ``HookIntegrator.reconcile_dropped_targets`` is 

6still the sole public entry point every caller uses; everything here is a 

7private implementation detail invoked only from that one method, and all 

8JSON mutation still runs through ``HookIntegrator._clean_apm_entries_from_json``, 

9the unchanged, single canonical primitive for merge-hook JSON writes. 

10 

11## Why this exists 

12 

13``HookIntegrator.sync_integration``/``reconcile_after_removal`` are 

14intentionally scoped (#2250) to the SAME resolved ``targets`` the rebuild 

15loop uses -- correct for that bug, but it permanently walls prune/uninstall 

16off from a target DROPPED from ``targets:`` entirely, since the rebuild loop 

17never touches it again. ``reconcile_dropped_targets`` is the canonical owner 

18of that gap: called once from ``manifest_reconcile. 

19reconcile_dropped_merge_hook_targets`` with the complement of the caller's 

20active/declared target union (see that module for the "allowed = active | 

21declared" rule). 

22 

23Names not registered in ``_MERGE_HOOK_TARGETS`` (e.g. ``copilot``, which uses 

24per-file, not merged, hook deployment already tracked/cleaned via 

25``deployed_files``) are silently skipped -- only true merge-hook targets are 

26acted on here. 

27 

28## Fail-closed partial-state handling 

29 

30This is stricter than ``_clean_apm_entries_from_json``'s best-effort posture 

31for its existing prune/uninstall callers (unchanged): a sidecar-only orphan 

32(native JSON absent, ownership sidecar remains -- a case that primitive's own 

33early-return never reaches) is validated as parseable before being unlinked, 

34and any malformed native/sidecar JSON is left byte-identical with an 

35actionable warning logged, never silently swallowed. 

36"""

98def _reconcile_sidecar_only_orphan(sidecar_path: Path, stats: dict[str, int]) -> None: 

99 """Remove an ownership sidecar whose native hook JSON is already gone. 

100 

101 ``_clean_apm_entries_from_json`` never reaches this state (it returns 

102 immediately when the native file is absent), so a sidecar left behind 

103 lingers forever in every existing caller. Validates the sidecar parses 

104 before deleting it -- malformed JSON fails closed (left in place, 

105 counted as an error, warned). 

106 """ 

107 try: 

108 with open(sidecar_path, encoding="utf-8") as f: 

109 json.load(f)

111 stats["errors"] += 1

121 exc,
