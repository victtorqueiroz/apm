1"""Mutable state passed between install pipeline phases. 

2 

3Each phase is a function ``def run(ctx: InstallContext) -> None`` that reads 

4the inputs already populated by earlier phases and writes its own outputs to 

5the context. Keeping shared state on a single typed object turns implicit 

6shared lexical scope (the legacy 1444-line ``_install_apm_dependencies``) 

7into explicit data flow that is easy to audit and to test phase-by-phase. 

8 

9Fields are added to this dataclass incrementally as phases are extracted from 

10the legacy entry point. A field belongs here if and only if it is read or 

11written by more than one phase. Phase-local state should stay local. 

12""" 

13
