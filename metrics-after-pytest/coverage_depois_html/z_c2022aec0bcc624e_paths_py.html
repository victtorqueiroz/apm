1"""Cache root resolution and escape hatch handling. 

2 

3Resolves the platform-appropriate cache directory following standard 

4conventions: 

5- Unix: ``${XDG_CACHE_HOME:-$HOME/.cache}/apm/`` 

6- macOS: ``$HOME/Library/Caches/apm/`` (or XDG if explicitly set) 

7- Windows: ``%LOCALAPPDATA%\\apm\\Cache\\`` 

8 

9Escape hatches 

10-------------- 

11- ``APM_CACHE_DIR=/path``: Override cache root entirely. 

12- ``APM_NO_CACHE=1``: Use a per-invocation temp directory (cleaned at exit). 

13- ``--refresh`` flag (handled by caller): Force revalidation on cache hit. 

14 

15Precedence: ``--no-cache`` > ``APM_NO_CACHE`` > ``APM_CACHE_DIR`` > default. 

16 

17Security 

18-------- 

19- Cache root validated: must be absolute (after ~ expansion), no NUL bytes. 

20- Directories created with mode 0o700. 

21- Path validated via ``ensure_path_within`` before any shard access.
